# 色彩、材质与背景比较

按 [workflow-1.0.md](workflow-1.0.md) 第 5 步，在形体选定后展开。Agent 根据需求、已有品牌色与选图判断是否需要颜色探索；已明确黑白或已选色时可以缩减/跳过并记录，不强迫单独选择十组色板。

## 两类 Section 与独立 Palette

1. **色彩与材质 Section**：每个选中形体约 25 个有意义的方案。行列按颜色或材质轴组织：比颜色时固定材质，比材质时固定配色；不要把两个变量随意混在每张图里。
2. **背景 Section**：单独比较背景颜色、材质和空间层次，数量按实际差异决定。复用 Background 区，不强制三种背景或再做整套笛卡尔积。
3. **Palette Section**：记录本轮实际使用的可编辑角色色块与同形小预览，不额外制造固定数量的色板选择关卡。选色与组合方案在同一轮收敛。

继承用户限定的品牌色或白底。候选色从当前参考提炼，不继承文档平台品牌。仅 RGB 改变时保留 gradient type / transform / stop positions / stop alpha、paint/layer opacity、blend mode、描边、效果和几何；细节见 [modular-design.md](modular-design.md)。

## 展示和选择

- 在原有相关区下方或邻近空白处建区，保持用户历史布局。Auto Layout 排列，尺度、光照和对照变量一致。
- Palette 按背景、主体、表情、辅助图形、细节、高光/阴影等适用角色展示原生色块，角色不是必须全部出现的颜色数量。
- 使用稳定编号与原生标题，例如 `C01 / 湖蓝 · 轻透`。不加说明卡或 HEX 文本页；项目记录保存色值、来源与参数。
- 真正截图检查全部变体：色块与图形可见、无重复占位、轮廓与层间对比清晰，渐变无突兀色带。检验主体/背景、表情/主体、按键/键盘的分离度。
- 用户用编号或 Comment 选择组合；允许取 A 的形体、B 的中景、C 的背景，按锚点与层级组合。普通偏好无回复按主流程暂选，不声称得到最终确认。
- 配色不满意时按具体问题补参考，保持已认可几何。纯色不强加渐变，单色域探索不凑彩虹。

## 记录

palette-selection.json 保存实际 section/node IDs、target/actual_count、palette IDs、来源、角色 HEX/alpha、渐变参数、预览几何、视觉验收及 selected/delegated/provisional 状态。继续前重读 Figma，保留用户改色和删选。Figma 不可用时保留可编辑 SVG 与预览，并明确同步待完成。
