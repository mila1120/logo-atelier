# 品牌色板：10 组搭配供用户选择

完整流程在 Reference 最终精选、背景提炼完成后执行本步骤。局部改图不重跑；用户单独要求探索色板时可直接进入。实际画出可编辑色板并放进项目 Figma，不能只返回色值清单或聊天中的配色建议。

本区是 `modular-design.md` 分层工作台中的独立 Palette Section，与六个角色区和 Composition / Final 区相连。色板数量不等于原创形态方向或精细变体数量。保存配色与材质为不同参数集合；“保持渐变与透明度，只换颜色”时锁定渐变类型、方向、色标位置、alpha、图层透明度及高光/阴影，只改授权角色的颜色。

## 提炼与搭配

读取当前项目的品牌色 Token、用户明确指定的色值和保留的参考图，再探索 **10 组不同的配色搭配**。已有确定品牌色作为约束，变化来自辅助色、明度、饱和度和前后景关系；用户限定蓝色时，十组都在允许的蓝色范围内，不强行凑成彩虹。没有明确色值时，把从参考中提炼的颜色标为候选，不冒充官方品牌色。

每组用相同角色顺序展示：背景色、品牌主色、辅助色、点缀/高光色、深色/阴影色。每个色块是可独立编辑的 Figma 原生矩形，精确记录 HEX 和透明度。五个角色用于比较，不意味着最终 Logo 必须同时使用五种颜色。用户锁定的白底等颜色在十组中保持一致。

十组须有可辨别的搭配差异，不能只改编号或进行肉眼难辨的微调。延续本项目所选风格，不把某个案例的蓝色、低饱和或液态材质写成通用默认。用户允许渐变时，每组可加一条真实矢量渐变样本，记录类型、方向、色标位置和透明度；纯色方向不强加渐变。渐变是主色的应用方式，不代替独立色块。

## Figma 展示

1. 先读取 Background Section 的实际位置、尺寸及邻近节点，创建或复用 `Palette / 品牌配色 · 10 组` Section，放在背景区下方，左边对齐并留出间距。多个历史背景区并存时以本次使用的背景组为锚点；下方被占用时放到下方最近的空白区域，不覆盖、搬移或删除用户已有内容。
2. 用原生 Auto Layout 排列十张配色卡，通常两行五列；尺寸和间距一致。每卡包含五个色块，并用同一个简单几何样本展示主色与背景色的关系。有已选 Logo 时可复用其轮廓作为小预览；没有时用中性圆角方块，不在选色阶段新增 Logo 概念。
3. 预览沿用已提炼的背景材质，十组之间保持同一几何、大小、光照与材质参数，以便比较颜色。卡片外框透明，露出 Section 的中性底色；色板中的背景色色块与预览中的实际背景仍保留。
4. 名称仅放在原生 Section、frame、layer 标题中，例如 `P01 / 清透青蓝`、`Primary / #4285FF`。不加画布文字解释、HEX 文本标签或文字页。颜色来源、推导与使用比例存入项目记录。
5. 截图检查全部十组：色块实际可见、数量正确、不重复、不截断；主色和背景在小预览中可辨，透明色显示正确，渐变无突兀色带。不能仅凭创建成功宣称完成。

## 用户选择与后续应用

完成可见色板后，在对话中附 Section 链接，让用户选一个主方案，可加一个备用，例如：“选最喜欢的 P01–P10，或直接在 Figma 保留想用的配色。”这次选择针对实际画出的搭配，不重复品牌问卷。用户此前已明确选择对应搭配或委托选择时沿用并记录；仅提供参考色不自动视为接受某一组搭配。

用户选择后再批量应用到后续彩色 Logo 方案。等待时可继续已授权的黑白构形、来源核验和技术检查；不要自行把十组全部套用到大量 Logo。用户明确要求整批配色探索或跳过选择时按其要求执行并记录，不额外要求确认。

继续前重读 Figma 中的色板，保留用户对色值、顺序及删选的修改。被删除的搭配不自动补回。只改颜色与相关色彩效果，不用一次选色授权更换几何或背景结构。

## 项目记录

在项目目录保存 `palette-selection.json`：

- file_key、page_id、background_section_id、palette_section_id、target_count=10、actual_count；
- 每组 palette_id、name、figma_node_ids、source_reference_ids、用户锁定色值、五个角色的 HEX/alpha、可选 gradient 的 type/stops/positions/transform；
- 预览使用的背景与前景 node_id、截图或渲染证据、视觉检查结果；
- status（draft / awaiting_palette_selection / selected / delegated / skipped_by_user）、selected_palette_ids、用户确认或委托原话、应用范围。

保存配色来源与确认状态，不声称候选颜色已成为正式品牌规范。Figma 不可用时可交付可编辑 SVG 色板与预览，并如实标记导入待完成。
