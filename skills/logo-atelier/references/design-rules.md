# Fixed aesthetic rules

Judge the unstyled mark before its mockup. Prefer one recognizable silhouette, intentional negative space, coherent curve/angle grammar, optical rather than merely arithmetic centering, and consistent visual weight. Complexity is earned by meaning; never demand minimalism when the brief calls for an expressive mascot. A mascot/IP direction still needs a simplified small-size mark.

Build a rationale: product fact → intended perception → core metaphor → geometry. Every extra element must strengthen meaning or recognition. Avoid generic spark/star/gradient defaults unless the concept specifically earns them. Distinct concepts must differ in structure, not only color.

Use a 1–5 anchored rubric, with evidence for each score: 1 fails the brief, 3 works with explicit weaknesses, 5 compelling and robust across tested contexts. Suggested weights: brand relevance 25%, distinctiveness 20%, silhouette/recognition 20%, optical craft 20%, adaptability 15%. Weighted scores support comparison only; do not imply objective quality or trademark clearance. A fatal readability/production defect cannot be offset by a high average. User-approved priorities may change weights, record why.

Hard gates: real vector geometry; readable intended use; no accidental clipping; no external resources; no unexplained geometry changes from rendering; necessary foreground/background separation. Document-reference provenance and obvious similarity review are required, not a claim of legal clearance.

A reference entry records URL/author if available, observation, transferable principle, excluded literal features and source-use constraints known from the source. References are not orders to imitate.

Before concept generation, translate the user's selected real app references into 3–5 concrete visual rules: silhouette occupancy, geometry/curve grammar, foreground/background relationship, palette and gradient span, and depth/material treatment. Record which reference supports each rule and what literal features must not be copied. Compare new concepts beside the selected references at the same small icon size; reject generic ornamental stars, excessive beveled depth and unmotivated gradients when they contradict the selected direction. A reference board informs taste; it is not proof of production readiness, which still requires the master and rendering checks.
