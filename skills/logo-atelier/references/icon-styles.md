# iOS 图标风格选项

这是可复用的设计预设分类，不是 App Store 官方热度排名。核验日期：2026-09-20。Apple 的当前图标指南与 WWDC 图标课程支持分层设计及多种系统外观；App Store Awards 是应用奖项，不能当成图标风格票选。若要引用某个现有 App 的图标作为例子，先实际查看其当前商店图标，不凭应用名称猜测风格。

| ID | 用户选项 | 可复用构建约束 |
|---|---|---|
| geometric | 极简几何 | 单一主轮廓、明确负空间、少量纯色；SVG 为母版，统一线宽/圆角规则 |
| luminous | 渐变光感 | 简洁矢量符号，受控渐变和局部亮光；参数记录渐变色标、方向、亮区与对比，去掉光效仍能识别 |
| soft-3d | 柔和 3D | 一个圆润主体、浅浮雕或有限厚度；固定相机、光向、材质和阴影参数，保留矢量轮廓与无材质版本 |
| layered-glass | 分层玻璃 | 分离前景与背景，受控半透明；采用适用的 Icon Composer 工作流验证系统外观，不能用一张烘焙高光 PNG 冒充原生动态效果 |

共同交付要求：1024 方形构图源稿、可编辑轮廓、独立前背景、风格参数、实际小尺寸渲染、目标系统外观检查。复杂材质不强行声称为纯 SVG；位图材质与几何母版分别交付。风格选项本身不代表完成生产验收。

默认给四项以便比较，按项目缩减；手绘/吉祥物仅当需求契合时替换某项，不因为模板存在就加入。不要让每个项目都自动采用玻璃或渐变。色彩由当前项目决定，不继承第三方平台品牌色。
